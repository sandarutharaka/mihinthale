# Cached original datasets

osm.json is the successful 707-object OSM bounding-box API export. elevation.tif is the complete Copernicus GLO-30 tile (47,178,963 bytes). Their .source.json sidecars record retrieval time, licence, coordinate metadata and SHA-256. Failure records describe earlier unsuccessful attempts and are not used as data. See ../../docs/sources.md and ../../docs/data-preparation.md.
